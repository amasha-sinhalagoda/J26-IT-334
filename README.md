# J26-IT-334 Research Workspace

Research workspace for the J26-IT-334 project, containing project administration,
research literature, datasets, reports, presentations, media, diagrams, and source
code.

## Workspace structure

| Folder | Purpose |
| --- | --- |
| `01_Project_Administration` | TAF documents, agreements, letters, requirements, and official correspondence |
| `02_Research_Literature` | Research papers and meteorological references |
| `03_Datasets` | Current, received, archived, and reference datasets |
| `04_Proposal_Reports` | Proposal material, final reports, and manuals |
| `05_Presentations` | Working slides and final submission packages |
| `06_Video_Media` | Scripts, presentation videos, IDMERS clips, and final videos |
| `07_Diagrams_Notes` | System diagrams, planning notes, and supporting images |
| `08_Source_Code` | `Component_App` and the `Research_Project` Python application |
| `99_Archive` | Reserved for obsolete material that should be retained but not actively used |

Folders are numbered to keep the workspace order stable. New files should be
placed in the most specific folder rather than left at the repository root.
